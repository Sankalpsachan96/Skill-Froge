# Skill-Froge 🚀
> ⚠️ **Project Status:** This project is currently an **Initial Prototype / MVP**. Core features are under active development.

An AI-powered skill exchange platform where users can learn, teach, and trade technical skills seamlessly. Built to foster peer-to-peer learning with automated skill verification.

## Key Features (Prototype Scope)

1. **Peer-to-Peer Skill Trading:** Connect with other developers to exchange skills.
2. **AI Skill Verification:** Automated verification system to validate user skills (Backend - In Progress).
3. **Interactive Dashboard:** Seamless UI for managing profile and learning sessions.
4. **Live Deployment:** Hosted on Vercel for fast performance testing.
